# dostyzaluzie.cz — сайт с админкой

Статический сайт, который собирается из JSON-файлов. Заказчик правит контент через админку на `/admin` (Decap CMS) и кодом не занимается.

## Структура

```
content/              ← всё, что редактирует заказчик (админка пишет сюда)
  cenik.json          ceník (цены)
  sluzby.json         služby (карточки услуг)
  realizace.json      3 главных проекта + фото для галереи «více»
  recenze.json        отзывы
  nastaveni.json      телефон, e-mail, переключатель «Přijímá zakázky»
src/
  index.template.html шаблон страницы (дизайн), плейсхолдеры {{...}}
  dekujeme/           страница «спасибо» после отправки формы
admin/
  index.html          админка Decap CMS
  config.yml          какие поля видит заказчик (подписи на чешском)
images/realizace/     фото (сжаты до 1920 px)
images/uploads/       сюда попадают фото, загруженные через админку
build.js              сборка без зависимостей: node build.js → dist/
netlify.toml          настройки сборки для Netlify
NAVOD.md              инструкция для заказчика (на чешском)
```

Локальная проверка: `node build.js`, потом открой `dist/index.html` или запусти `npx serve dist`.
Дизайн меняется в `src/index.template.html`, набор полей в админке — в `admin/config.yml`.

## Деплой (один раз, ~20 минут)

1. **GitHub.** Создай репозиторий (можно приватный), ветка `main`. Залей в него всё содержимое папки (кроме `dist/`). Можно прямо через сайт: *Add file → Upload files*, перетащить файлы.
2. **Netlify.** На [app.netlify.com](https://app.netlify.com): *Add new project → Import an existing project → GitHub* → выбери репозиторий. Настройки сборки подтянутся из `netlify.toml`, нажми *Deploy*.
3. **Вход в админку.** В настройках проекта:
   - *Identity → Enable Identity*;
   - *Registration preferences → Invite only*, чтобы никто посторонний не смог зарегистрироваться;
   - *Services → Git Gateway → Enable*;
   - *Identity → Invite users* → e-mail заказчика. Он получит письмо, перейдёт по ссылке, задаст пароль, и его перекинет в `/admin`.
   - Пригласи и себя, чтобы проверить, что всё работает.
4. **Форма заявок.** *Forms → Enable form detection*, затем *Deploys → Trigger deploy*. Потом *Forms → Form notifications → Email notification* на почту заказчика. Заявки будут приходить на e-mail и храниться в панели Netlify. Защита от спама (honeypot) уже встроена.
5. **Домен.** *Domain management → Add a domain* → `dostyzaluzie.cz`. Потом у регистратора либо поменяй NS-серверы на Netlify DNS (проще), либо пропиши A/CNAME-записи, которые покажет Netlify. HTTPS включится сам.

После этого каждое «Publish» в админке создаёт коммит в GitHub, Netlify пересобирает сайт, и через ~1 минуту изменения уже онлайн. Если заказчик что-то сломал, любую версию можно откатить: *Deploys → выбрать старый → Publish deploy*.

## Что осталось / можно улучшить

- **Цены.** Сейчас во всех строках стоит «na dotaz». Реальные цифры заказчик впишет сам через админку.
- **Телефон и отзывы.** Если +420 602 123 456 и три отзыва — заглушки, их нужно заменить до запуска (тоже через админку).
- **Фото с водяным знаком «Obsah generovaný pomocí AI».** Это пометка Samsung Galaxy AI после редактирования. Лучше загрузить оригиналы без правок.
- **Tailwind CDN.** Работает, но в консоли пишет предупреждение, и страница грузится чуть медленнее. Позже можно перейти на собранный CSS (Tailwind CLI в шаге сборки).
- **Письма-приглашения Netlify Identity приходят на английском.** Шаблоны можно перевести: *Identity → Emails*.
- Тексты блоков «O mně» и hero пока лежат в шаблоне. Если заказчик захочет менять и их, нужно добавить ещё один JSON и коллекцию в `config.yml` по тому же принципу.
